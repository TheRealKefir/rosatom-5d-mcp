Управляет парком принтеров: отправляет G-код, ставит в очередь, начинает/останавливает
печать, запрашивает статус, делает скриншот с веб-камеры.

ВЫЗЫВАЙ КОГДА:
- Пользователь просит отправить файл на принтер.
- Нужно проверить статус принтера.
- Нужно остановить печать (дефект, авария).
- Нужно сделать фото с веб-камеры для анализа.

НЕ ВЫЗЫВАЙ КОГДА:
- Нет G-кода (сначала slice_model).
- Пользователь не указал принтер (спроси или выбери свободный).
- Нет подтверждения пользователя на начало печати.

ВОЗВРАЩАЕТ: JSON со статусом операции, ID задания, прогнозом завершения.
