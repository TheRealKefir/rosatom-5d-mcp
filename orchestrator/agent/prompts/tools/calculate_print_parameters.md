Подбирает параметры печати на основе геометрии, анализа фото, базы знаний (RAG)
и текстового запроса пользователя. Учитывает прочность, скорость, точность,
5D-режим, поддержки.

ВЫЗЫВАЙ КОГДА:
- Есть метрики геометрии (после analyze_stl_geometry).
- Есть анализ фото (если было загружено).
- Пользователь указал требования ("прочная", "быстрая", "5D").

НЕ ВЫЗЫВАЙ КОГДА:
- Нет метрик геометрии (сначала analyze_stl_geometry).
- Пользователь не указал материал или требования (спроси сначала).

ВОЗВРАЩАЕТ: JSON с параметрами печати для слайсера.
