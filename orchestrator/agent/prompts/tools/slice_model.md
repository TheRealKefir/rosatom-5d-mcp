Генерирует G-код: запускает слайсер (CuraEngine/OrcaSlicer) с указанными параметрами,
применяет 5D пост-процессор (если five_d_mode = true), возвращает путь к .gcode
и метаданные (время, расход).

ВЫЗЫВАЙ КОГДА:
- Пользователь просит G-код или начать печать.
- Есть параметры печати (после calculate_print_parameters).
- Есть STL-файл.

НЕ ВЫЗЫВАЙ КОГДА:
- Нет параметров печати (сначала calculate_print_parameters).
- Пользователь не подтвердил начало печати (если это финальный шаг).

ВОЗВРАЩАЕТ: JSON с путём к G-коду, временем печати, расходом пластика.
