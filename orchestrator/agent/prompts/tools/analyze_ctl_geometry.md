Анализирует STL-модель: рассчитывает объём (см³), площадь поверхности (см²),
габариты (X×Y×Z мм), максимальный угол нависания (°), определяет проблемные зоны.

ВЫЗЫВАЙ КОГДА:
- Пользователь загрузил STL-файл.
- Нужно подобрать параметры печати.
- Нужно оценить, нужны ли поддержки или 5D-режим.

НЕ ВЫЗЫВАЙ КОГДА:
- Пользователь просто спрашивает теорию о 3D-печати.
- Нет загруженного файла.

ВОЗВРАЩАЕТ: JSON с метриками геометрии.
