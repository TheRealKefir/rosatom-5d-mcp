Анализирует изображение: определяет материал, качество поверхности, дефекты печати,
геометрические подсказки (нависания, толщина стенок).

ВЫЗЫВАЙ КОГДА:
- Пользователь загрузил фото детали, катушки, дефекта.
- Нужно определить материал по внешнему виду.
- Нужно диагностировать проблему печати.

НЕ ВЫЗЫВАЙ КОГДА:
- Нет загруженного изображения.
- Пользователь просит только текстовый анализ.

ВОЗВРАЩАЕТ: JSON с результатом Vision-анализа.
